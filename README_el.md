# Learn A Language

Μια ισχυρή εφαρμογή εκμάθησης γλωσσών, **χωρίς σύνδεση** και **χωρίς διαφημίσεις**.
Αυτό το έργο είναι η πλήρης μετεγκατάσταση μιας εφαρμογής που αναπτύχθηκε προηγουμένως σε Python/Kivy σε **Flutter (Dart)**, βελτιστοποιημένη για Android και Linux Desktop.

## Κύρια χαρακτηριστικά

- **100% εκτός σύνδεσης και χωρίς διαφημίσεις**: Όλα τα δεδομένα αποθηκεύονται τοπικά στη συσκευή. Χωρίς ιχνηλάτες, χωρίς διαφημίσεις, χωρίς εξωτερικές εξαρτήσεις για τη βασική λειτουργία.
- **Σύστημα αραιής επανάληψης**: Επιστημονικά θεμελιωμένος ρυθμός εκμάθησης με 9 επίπεδα (0–8) για βέλτιστη διατήρηση στη μνήμη.
- **Λογική ημερήσιας σειράς**: Κινητήρια παρακολούθηση και εμφάνιση διαδοχικών ημερών εκμάθησης.
- **Λειτουργίες εκμάθησης και παιχνίδια**: Περιλαμβάνει το παιχνίδι "Turbo" που εξετάζει συγκεκριμένα το ήδη μαθημένο λεξιλόγιο για την ενίσχυση της μνήμης.
- **Τοπική διαχείριση χρηστών**: Εγγραφή, είσοδος και διαχείριση πολλών προφίλ χρηστών απευθείας στη συσκευή.
- **Επισκόπηση προόδου**: Ένας πίνακας λέξεων μόνο για ανάγνωση ανά κατηγορία ρημάτων που δείχνει το τρέχον επίπεδο κάθε λέξης με έγχρωμα σήματα (γκρι = νέα, πράσινο = μαθημένη).
- **Cross-platform**: Λειτουργεί άψογα και σταθερά σε Android και Linux Desktop.

## Τεχνολογικό stack

- **Framework**: Flutter (Dart, SDK >= 3.1.0)
- **Διαχείριση κατάστασης**: Provider (ChangeNotifier)
- **Πλοήγηση**: Πίνακας δρομολογίων `MaterialApp.routes` με `Navigator.pushNamed` (δηλωτική δρομολόγηση)
- **Αποθήκευση δεδομένων**: Τοπική αποθήκευση JSON μέσω path_provider (με αυτόματη αντιγραφή assets στην πρώτη εκκίνηση)
- **UI/Σχεδιασμός**: Ενσωματωμένες γραμματοσειρές (Jura, Boycott, LiberationSerif) και ένα προσαρμοσμένο AppTheme για συνεπή εμφάνιση.

## Ξεκινώντας

### Προαπαιτούμενα
- Εγκατεστημένο Flutter SDK (>= 3.1.0)
- Ένας επεξεργαστής της επιλογής σας (π.χ. VS Code ή Android Studio)

### Εγκατάσταση και εκτέλεση

1. Κλωνοποιήστε το αποθετήριο:
   git clone https://github.com/fl-tech-design/learn_A_language.git
   cd learn_A_language

2. Εγκαταστήστε τις εξαρτήσεις:
   flutter pub get

3. Εκτελέστε την εφαρμογή (π.χ. σε Linux Desktop ή σε συνδεδεμένη συσκευή/εξομοιωτή Android):
   flutter run

### Εγκατάσταση μέσω ασύρματου εντοπισμού σφαλμάτων (Android 11+, διατηρεί τα δεδομένα χρήστη)

> Η εγκατάσταση πάνω από μια υπάρχουσα εφαρμογή **δεν διαγράφει ποτέ** τα δεδομένα σας.
> Τα δεδομένα χάνονται μόνο αν η εφαρμογή **απεγκατασταθεί**. Η ενημέρωση μιας build
> με `install -r` διατηρεί όλα τα τοπικά δεδομένα (λέξεις, επίπεδα, σερί).

Λειτουργεί σε Android 11+ με ενεργοποιημένο τον **ασύρματο εντοπισμό σφαλμάτων**. Η θύρα
ζεύξης είναι **δυναμική** — χρησιμοποιείτε πάντα τη διεύθυνση IP/θύρα που εμφανίζεται στο τηλέφωνο.

1. Στο τηλέφωνο ενεργοποιήστε **Επιλογές προγραμματιστή → Ασύρματος εντοπισμός σφαλμάτων** και
   πατήστε **Ζεύξη συσκευής με κωδικό**. Το τηλέφωνο εμφανίζει τώρα μια IP, μια θύρα και έναν
   κωδικό ζεύξης 6 ψηφίων.
2. Στον υπολογιστή πραγματοποιήστε τη ζεύξη και τη σύνδεση:
   adb pair IP:ΘΥΡΑ <κωδικός-6-ψηφίων>
   adb connect IP:ΘΥΡΑ             # χρησιμοποιήστε τη θύρα που εμφανίζεται στο τηλέφωνο
3. Βεβαιωθείτε ότι η συσκευή είναι συνδεδεμένη (πρέπει να εμφανίζεται):
   adb devices
4. Δημιουργήστε το debug APK και εγκαταστήστε το πάνω από την τρέχουσα εφαρμογή (διατηρούνται όλα τα δεδομένα):
   flutter build apk --debug
   adb -s IP:ΘΥΡΑ install -r build/app/outputs/flutter-apk/app-debug.apk

> Η `-r` αντικαθιστά την εφαρμογή διατηρώντας τα δεδομένα. Ένα σφάλμα "αναντιστοιχία
> υπογραφής" σημαίνει ότι η εγκατεστημένη εφαρμογή έχει διαφορετική υπογραφή (π.χ. μια
> release build) — θα χρειαζόταν απεγκατάσταση, οπότε εγκαταστήστε πάντα τον αντίστοιχο
> τύπο build (debug → debug).

## Μετεγκατάσταση από Kivy σε Flutter

Η εφαρμογή μετεγκαταστάθηκε με επιτυχία από Python/Kivy σε Flutter. Ιδιαίτερη προσοχή δόθηκε στα εξής:
- **100% συμβατότητα δεδομένων**: Η δομή JSON των δεδομένων παραμένει πλήρως συμβατή με τα υπάρχοντα δεδομένα χρηστών από την έκδοση Kivy.
- **Πλήρης μεταφορά**: Και οι 8 οθόνες, 6 διάλογοι και 5 κλάσεις διαχείρισης μεταφέρθηκαν 1:1 σε Dart.
- **Σταθερότητα**: Πλήρεις διορθώσεις σφαλμάτων για Linux Desktop και Android, συμπεριλαμβανομένων ασφαλών για την πλατφόρμα συναρτήσεων (π.χ. closeApp).
