# Learn A Language

Мощное приложение для изучения языков, работающее **офлайн** и **без рекламы**.
Этот проект представляет собой полную миграцию приложения, ранее разработанного на Python/Kivy, на **Flutter (Dart)**, оптимизированную для Android и Linux Desktop.

**[English](README.md) | [Deutsch](README_de.md) | [Français](README_fr.md) | [Español](README_es.md)**

## Основные функции

- **100% офлайн и без рекламы**: Все данные хранятся локально на устройстве. Никаких трекеров, рекламы или внешних зависимостей для основного функционала.
- **Система интервального повторения**: Научно обоснованный ритм обучения с 9 уровнями (0–8) для оптимального запоминания.
- **Логика серий дней**: Мотивационное отслеживание и отображение последовательных дней обучения.
- **Режимы обучения и игр**: Включает игру "Турбо", которая целенаправленно проверяет уже выученную лексику для закрепления знаний.
- **Локальное управление пользователями**: Простая регистрация, вход и управление несколькими профилями пользователей непосредственно на устройстве.
- **Кроссплатформенность**: Нативно и стабильно работает на Android и Linux Desktop.

## Технологический стек

- **Фреймворк**: Flutter (Dart, SDK >= 3.1.0)
- **Управление состоянием**: Provider (ChangeNotifier)
- **Навигация**: go_router (декларативная маршрутизация)
- **Хранение данных**: Локальное хранение в формате JSON через path_provider (с автоматическим копированием ресурсов при первом запуске)
- **UI/Дизайн**: google_fonts (Jura, Boycott, LiberationSerif) и пользовательская AppTheme для единообразного внешнего вида.

## Структура проекта

Проект следует чистой, модульной архитектуре в каталоге `lib/`, обеспечивая удобство поддержки и масштабируемость:

lib/
├── main.dart            # Точка входа приложения
├── managers/            # Бизнес-логика (AppState, User, Vocab, Language)
├── screens/             # Экранные представления (Loading, Start, Learning, Settings и т.д.)
├── services/            # Сервисы (напр. FileService для JSON-персистентности)
├── models/              # Модели данных
├── widgets/             # Повторно используемые компоненты интерфейса
├── dialogs/             # Всплывающие окна и диалоги (Info, Login, GameOver и т.д.)
└── theme/               # Центральная цветовая палитра и ThemeData

## Начало работы

### Предварительные требования
- Установленный Flutter SDK (>= 3.1.0)
- Редактор по вашему выбору (напр. VS Code или Android Studio)

### Установка и запуск

1. Клонировать репозиторий:
   git clone https://github.com/fl-tech-design/learn_A_language.git
   cd learn_A_language

2. Установить зависимости:
   flutter pub get

3. Запустить приложение (напр. на Linux Desktop или подключённом устройстве/эмуляторе Android):
   flutter run

## Миграция с Kivy на Flutter

Приложение было успешно мигрировано с Python/Kivy на Flutter. Особое внимание было уделено следующим пунктам:
- **100% совместимость данных**: Структура данных JSON остаётся полностью обратно совместимой с существующими пользовательскими данными из версии Kivy.
- **Полный перенос**: Все 8 экранов, 6 диалогов и 5 классов-менеджеров были перенесены 1:1 на Dart.
- **Стабильность**: Обширные исправления ошибок для Linux Desktop и Android, включая платформенно-безопасные функции (напр. closeApp).

## Лицензия

Этот проект разрабатывается как приложение без рекламы и с приоритетом офлайн-работы, ориентированное на эффективное обучение без отвлекающих факторов.
